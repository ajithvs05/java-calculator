# Java Calculator 🧮

A simple calculator application developed using Java to perform basic arithmetic operations.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division

## 🛠️ Technologies Used

* Java

## 🎯 Purpose

This project was created to practice Java programming and understand basic arithmetic operations.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the Java source file in a Java IDE.
3. Compile and run the program.
